# Salary Benchmarking & Pay-Equity Gap Detector

A regression pipeline that predicts "fair" base pay from job-related factors, then checks whether
pay still differs by gender after controlling for those factors — the same adjusted-gap
methodology real HR/compliance teams use for pay equity audits. Deployed as a live Streamlit app.

**Live demo:** (https://silly-pens-find.loca.lt/)

## What this project covers

- **Dataset:** Glassdoor Gender Pay Gap dataset — 1,000 employees:
  `JobTitle, Gender, Age, PerfEval, Education, Dept, Seniority, BasePay, Bonus`
- **Key methodology choice:** the model is trained **without `Gender` as an input feature**. If a
  model still shows a residual (prediction error) that differs systematically by gender after
  seeing only job title, department, seniority, performance, education, and age, that residual is
  the **unexplained / adjusted pay gap** — the number a real pay-equity audit focuses on, as
  opposed to the raw (unadjusted) average difference in pay.
- **Models compared:** Simple Linear, Multiple Linear, Polynomial, Ridge, Lasso, ElasticNet, KNN
  Regressor, Decision Tree Regressor, Random Forest Regressor, XGBoost Regressor
- **Tuning:** GridSearchCV on Ridge/Lasso (`alpha`); RandomizedSearchCV on Random Forest and
  XGBoost
- **Evaluation:** residual plots, actual-vs-predicted (colored by gender), regularization
  coefficient paths, feature importance, RMSE/MAE/R² comparison, VIF multicollinearity check
- **Pay-equity analysis:** raw gap vs. adjusted gap comparison, Welch's t-test for statistical
  significance, per-department adjusted gap breakdown, and an Underpaid/Fair/Overpaid flag per
  employee
- **Deployment:** a saved model artifact (`salary_model.joblib`) and a Streamlit app (`app.py`)
  where you enter an employee's job factors + actual pay and get an instant fairness check

## Running the notebook

Open `Salary_Benchmarking_Pay_Equity.ipynb` in Jupyter, Colab, or Kaggle Notebooks and run all
cells top to bottom. It will:
1. Load the dataset (tries Kaggle first, automatically falls back to a public GitHub mirror if
   Kaggle auth isn't set up — no API key required either way)
2. Run the full EDA, preprocessing, training, tuning, and pay-equity analysis pipeline
3. Write `app.py` and `salary_model.joblib` to the working directory

## Running the app locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Then open the local URL Streamlit prints (usually `http://localhost:8501`).
